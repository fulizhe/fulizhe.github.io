防火的收益是负数：为什么理性人不做长远优化

2026-09-23T15:40:00.000Z2026-09-25T12:01:55.820ZChina

前言

我在一个没有行政权力的位置上待了很多年。这些年我摸索出一套自认为相当可靠的做法：不申请、不立项、不要资源，专挑那些没人有理由拦的切口，把改变一点点塞进去。这套东西我写成了一个系列，最近一篇刚发出去（同源方法论见 批准很贵，默许很便宜：一个 nginx 页面穿过组织的三年），自认为已经把账算得很清了。

直到前几天群里出现一段对话，我才发现自己漏算了一项，而且是最重的那一项。

1. “为什么不早说”不是问句，是判决书

对话是这样的：

昨天制图的，你们平台加了个 https，让我们安装证书

我今天跟甲方说得安装证书才能使用，甲方说你们为啥不早点通知我们

我内心一万个草泥马，我也是昨晚才被通知。

说这话的是一位项目经理。他夹在中间，两头受气，而且两头都不该由他受。

但我盯着的不是他的委屈，是甲方那句话。

“为什么不早说“的语法是疑问句，功能是判决书。

甲方要的从来不是答案。他要是真想知道原因，问题应该是”这件事卡在哪一步”。而”为什么不早点通知我们“这句问法里，已经预先认定了一件事：责任在你，只是你动作慢了。这是一个把责任钉死的动作，不是一次求知。

而且这句话有个硬伤：

没人能通知一个还没做出的决定。

他们没早说，是因为”上 https”这个决定本身就是前一天才定的。甲方问的是”通知为什么迟”，真正的问题是”决定为什么迟”。这两件事不在同一个责任人身上。

这里还有一个细节值得说，因为它把整件事的性质都改了：那次 https 改造，不是外部平台提的要求，是内部技术做到最后评估才发现的。

如果是外部要求，至少还有一个外部责任方。但它既然是内部评估的产物，就意味着：没有任何人对”上 https 需要什么”负责。 需求传下去了，前置条件没人评。技术评估被排在交付流程的最后一步，紧贴着交付。

一个团队如果对”上 https 需要什么”有一张清单，这件事本该在第一周被提出来，而不是在交付前一天。

2. 骂”素养”是最舒服的归因

群里另一位给的判断是：”根本没全套方案，就是遇到问题再说，走一步看一步””说白了都是草台班子”。

这两句都对。但它们都在止痛，不在治病。

先把事实摆正：https 要证书不是彩蛋，是标配。做过一次 https 的人，脑子里就该长出一张清单——域名、证书、备案、续期、混合内容、证书链。这不需要什么”全套方案”，没人有全套方案，但人人都该有个开头。

所以问题不出在”没有预案”，出在”没人觉得这需要预案“。

专业主义可以浓缩成一句话：

把别人会惊讶的事，变成你已经预期的事。

草台班子不是因为出错。草台班子是因为出了本该料到的错，却像见了鬼。

（这个判断我在另一篇里从”起火”的角度写过一遍，讲的是纵火的人同时扮演消防员的那个闭环，见 纵火犯抱团之后：切香肠、烟囱口与产品底线的流失。今天这篇讲的是同一条链上更下游的那一段。）

但”素养论”有个致命的舒服之处：它不可改。

骂素养的潜台词是”这帮人就这样了”。骂完之后，你什么也不用做，继续受着。而”世界是个草台班子”是同一味药的加强版——它把”体系性失能”和”个体选择”糊成一件，让你从一个前排的批判者，慢慢变成后排的共犯。

3. 防火的收益不是零，是负数

要理解这件事为什么会反复发生，得先看清两类工作的收益曲线。

救火是尖峰。 平时贴着零轴走，事故一响，曲线猛地蹿起来：加班、顶住、被表扬、被记住。收益是正的、即时的、可归因的。

防火是平线。 它全程贴地，因为它的成果叫”什么都没发生”。

这个道理不是新发现。《汉书》里有两千年前的原话（原文出处见「曲突徙薪」条）：

曲突徙薪无恩泽，焦头烂额为上客。

劝人把烟囱改弯、把柴火搬开的那位，没有恩泽；等到烧起来去救火、烧得焦头烂额的那位，是上宾。

但到这一步，故事只说了一半。真正的形状是——那条平线不是停在零轴上，它跨过去了，往下走。

为什么往下？

因为”什么都没发生”在别人眼里，会被翻译成另一句话：这家伙挺闲的。

于是你的产能被认领。不是”没人给你记功”这么简单——是有人开始给你派活，而且是”正经业务”的活，谁都挑不出错。

所以防火的收益是负数：零记功，加上被当成空余产能征用。

这种账面倒挂——你越做得好，越像没干啥事——我在另一篇里从记账口径的角度写过一遍（见 账本失明：为什么你越做得好，越像没干啥事），今天这篇要往下再走一层：那本账不光记不上你，还会倒过来扣你。

这才把那个困扰我很久的问题解答了：为什么理性人不做长远优化？

不是因为长远优化没有回报。是因为它有惩罚。

4. 阻力有两柄武器

我在前面那篇里写过一句自己比较满意的话：

阻力的武器从来不是”反对”，是审批权和资源分配权。

那时候我只把资源分配权用在了”借上”那条通道上，意思是”他不出资源”。现在我意识到，这柄武器是双向的。

审批权是第一现场：拦你的方案。立项吗？预算哪出？涉及线上，走个评审吧？先别急，等下次排期。

资源分配权是第二现场：不拦你的方案，直接把你的人拿走。”这个你熟，你来。””这块你顺手看一下。”

用的武器 审批权 资源分配权

第二现场更难防，就差在一句话上：他说”走个评审吧“，你能指着说这是拖；他说”这个你熟，你来“，你指着说什么？

而它最阴的地方在于：它伪装成机会。

第一现场的阻力你能识别，有人在拦你，你会警觉。第二现场的”业务安排”，你会读成信任、重用、领导还看重我。

很多人是被喂死的，而且死的时候心怀感激。

它不提供可反抗的对象。你没法骂”他又给我派活”——那听起来像矫情。

这种”救场救着救着变成了长工”的路径，我在这篇里拆过一遍（见 救场变长工，防卫性隐藏：戳破技术寄生者的“边界蚕食”与权力寻租）；今天要补的是它的前置条件——你得先表现得”闲”，才轮得到被救场。

5. 拆分的悖论

面对这种处境，方法论上的标准答案是”别贪大，把目标拆小，快速见效，先拿到一个胜利”。

这句话漏掉了它自己的反面：

能快速见效的那部分，恰恰是不能证明方向的那部分。

拆到最后剩下的，一定是旁枝末叶。

于是死循环成形了：你越努力快速见效，交出的证据越”小”；证据越小，领导越确认”这事没什么分量”；越没分量，越不支持；越不支持，你越只能靠小胜利续命。

短期见效与战略说服，在结构上是互斥的。

而且更麻烦的是：拿小胜利去要认可，本质上还是一次”申请”。

一申请，就回到审批轨道。

6. 一致性：没有人靠觉悟做事

写到这里，我想起自己写过的最狠的一句话（原话见 批准很贵，默许很便宜：一个 nginx 页面穿过组织的三年）：

维护不是自驱，是自利。所有靠觉悟维护的资产最后都死了。

我把这句话用在了用户身上，用它解释一个页面为什么能活三年。现在我要把它调转过来，对准上一个层级：

在一个没有长远激励的评价体系里，所有靠觉悟产生的远见，最后也都会死。

领导短视不是道德缺陷。它和我页面上的用户是同一个问题。

我不能一边用自利去设计页面（因为我相信觉悟不可靠），一边期待领导有远见。那和期待用户有自驱力，是同一个错误。

再往下还有一层，这层不太体面：群里那位骂甲方”严以律人，宽以律己”，我骂领导”只奖励救火不看长远”。

我们是同一种句式——都在要求一个系统的参与者，做出违背他自己算式的事。

7. 借侧的代价

想通了这一层，代价才浮出来。

我这些年只走借侧。借侧有效，黄页就是证据。但借侧是战术，做久了会变成人格。

一旦习惯了”绕过权力也能成事”，你会越来越不愿意正面处理权力。

正面处理权力的能力会不会退化？我原来的判断是”不可逆”。更准确的版本是：能力是可逆的，关系是不可逆的。

技能荒废了可以练回来。但”这个人从来不来找我”这个印象一旦固化，你在对方那里的默认标签就变成了”有事才出现的人”——而带着这个标签去正面沟通，比从零开始还难。

还有一层，是我自己文章里漏掉的。

我写过 AI 让资产耗材化（同源判断见 AI主导研发前夕的局内人观察：代码资产大贬值与工程范式重构）：页面不必再当作固定资产维护，过期不修，直接重生成。我还给出了三层结构——资产的入口、自动的燃料、人工的插槽。

但那个三层图里漏了一层：我自己。

入口能重生成，燃料能自动导出，插槽能靠盟友维护。唯独”在哪儿下刀、哪条缝不会被拦、把谁的自利绑上去”这套判断，不能上传、不能分享、不能自动生成。每换一个场景，都得我从零再走一遍。

我是这套系统里唯一不能重生成的那个部件。

这既是我的议价权，也是我的笼子：你越不可替代，你越被钉死在那个位置上。

8. 那这条路怎么走

三条，都不需要权力。

第一，主攻先例效应，而且当主线打，别当副产品。

我写过一句”一次失效之后，它就不再是绝对的了”。但反例真正的杀伤力不来自数量，来自两件事：可重复性，和由谁说出。

具体是三个动作：

建一本反例台账。 每一次”没走审批也成了”的事，记下四样：切口是什么、绕过了什么、谁在用、活了多久。这本台账不需要批准，也不需要给别人看——它是你自己的证据链。

让受益者替你转述。 反例必须从别人的嘴里出去。我要做的不是宣称”我绕过了审批”，而是提供素材，让用着它的人能说出那一句：”这东西当初没走流程，就自己敲的。”我早写过，盟友的嘴替我说的话，比我自己说重十倍（同一个机制见 左移的反噬：当烟囱口成了新的小工）。反例同理。

选下一个切口时，优先后验”它能不能和上一个构成一对”。 一个反例是偶然，两个同类反例并排就是规律。可重复性，才是先例真正的杀伤力。

而最关键的一击在这里：

你不需要审批权的持有者承认失效，你只需要他使用它。

使用即默许，默许即承认。他不必说”这没走审批也行”，他只需要在某一次汇报里，把这个未经审批的成果当成自己的成绩举出来。那一刻，审批权的绝对性就出现了第一道裂缝。

第二，补回正面通道，防止它报废。

处方有点反直觉：低频、非索取性的接触。

一个月一两次，不是请示，是同步。内容可以极简——我最近在弄什么、进度到哪、卡在哪。

目的不是要资源。目的是让”这个人会来找我说话”这句话，保持为真。

这是唯一一个能对冲”关系不可逆”的动作，而且它不需要任何权限，只需要时间。

第三，造模具，但要对自己诚实。

我手上真正可复制的资产不是黄页，是那五条切口判据。

但有件事得说清楚：我能外化方法，不能外化动机。 找缝的收益在零轴以下，别人不会因为手上多了一张判据就去找缝。

所以模具的真实价值不是解锁别人，是给我自己降本——把”识别缝”从凭直觉变成照着筛。

再往前一步更有意思：判据 + AI，可以批量筛切口。 这才是这个杠杆真正能被撬动的地方。

后记

《庄子》里庖丁解牛的段落（原文见《庄子·养生主》），我一直当作夸奖在读。

十九年，刀刃若新发于硎。因为他从不砍骨头，专找骨节之间的空隙，以无厚入有间，游刃有余。

我确实就是干这个的。找到缝，塞进去，不惊动任何人。

但我最近发现这句话还有另一面，而且那一面我以前没读进去：

他解了十九年，牛还是那头牛，也还是那么大。

刀很好，缝找得很准，一头牛变成了几千块肉。可是牛从来没有因为庖丁的手法好而变小过。

这大概是我这些年最准确的画像。我不打算改行——在没有权力的位置上，借侧确实是我唯一能走通的路，我会继续走。

但我得提醒自己一件事：庖丁的刀法再好，也从来没有把牛变小过。

封面解读

这张封面是一则钢铁巨兽式的自我画像——用一头牛的构造，把”借侧的手艺”和”它的上限”压缩进同一个画面。画面里没有任何人，这本身就是全文的第一个判断：这件事不是靠人办的，也没有人批准过它。

整头巨牛，由层叠的钢板块拼成 = 你要改造的那个对象。 不是敌人，不是堡垒，只是一头长在那儿的牛。它有体量、有厚度、有四条承重的腿。它挡你不是因为恨你，是因为它就是那样长着的。

牛身上布满几十道细如发丝的接缝，每一道都精确走在钢板的天然拼缝上 = 借侧的切口。 刀刀落在骨节之间，没有一处砍在骨头上。这是庖丁的手法：贴着纹理走，不硬碰。右侧那把躺在空地上的崭新长刀 = 那把十九年不曾卷刃的刀——因为它一直在避让最硬的部分。刀很干净，是它从不砍骨头的证据。

牛的轮廓、体量、站姿，一寸未改 = 全文最不肯放过的那一句。 切得再好，牛没有变小。缝开得再准，那头牛的重量一分没少。这张图不回答”接下来怎么办”，它只坚持一件事：手艺的完美，和对象的无动于衷，可以同时成立。

唯一的暖光，从每一道缝里漏出来 = 你拿到的全部收益。 整个大厅是冷青灰色的，光源在画面之外，只负责描出钢板的轮廓，不产生任何温度。唯一的暖色在牛的身体内部，只能从那些细缝里渗出一线。你不是造出了光，你只是找到了能透光的缝——而这些缝也是你唯一能拿到的报酬。

空无一人的巨大厂房、四边大面积的留白 = 没有见证者。 没有观众，没有裁判，没有谁走过来看一眼说”这活儿干得漂亮”。缝里透出的那点光，没有人给它记账。

一句话总结：封面用”一头体量纹丝不动的钢牛 + 满身精准到手术级的细缝 + 缝里唯一的那点暖光 + 地上一把崭新未用的刀”，把全文压缩成一幅画——你确实是个好庖丁，刀也确实一直很新；但那头牛，从来没有因为你的手艺好而变小过。

原始素材和基础语料（人工）

不动产-张无名：昨天制图的，你们平台加了个 https，让我们安装证书。我今天跟甲方说得安装证书才能使用，甲方说你们为啥不早点通知我们。我内心一万个草泥马，我也是昨晚才被通知。

夫礼者：根本没全套方案，就是遇到问题再说，走一步看一步。比如 https 部署，需要哪些前置条件这种。

不动产-张无名：说白了都是草台班子。甲方也是草台班子，只是严以律人，宽以律己。他们说的那些我也会说。让我按照那些套路搞，对不起，不可能。除非跟欧美一样，一件活干几年，那能跟你搞的规规矩矩的。

夫礼者：讨论下这个，我的思路一是对公司工作流程、人员能力和素养的思考，二来则是经典的世界是个草台班子。

夫礼者：不是道德问题，是激励问题。最近半年我都不咋说话了，因为已经真正认识到问题的根源来自领导，这个团队的根因。我想说明的是 https 配置这种通用需求应该是一个普遍需求，团队应该早就形成了一套标准化的流程；这其实还是领导问题，不奖励长远决策，只看救火行为。欧美不是活干得久，是不确定性有价格，这个我信服。另外这段对话不是我的发言，是群里的一位现场的项目经理。这个转 https 好像是内部技术最后评估发现的。

夫礼者：骂”不奖励长远决策”的人，本该是团队里第一个给”没出事”记功的人。我没有任何行政权力。”这张单子挡掉 2 个风险、省了 3 天”，这种没有发生的最多口头表扬。

夫礼者：”离你最近的那一层，通常是阻力的第一现场”，我再加一句：阻力第二现场来自——问题太大难以快速见效，拆分之后的、短期见效的旁枝末叶，领导们又看不出这件优化背后的长远，兴趣寥寥，然后认为你太空闲，安排更多其它业务要求你做。

夫礼者：黄页里的那篇文章想要说明的是，我没有行政权，唯一有效的是插缝。

续补（本轮扩写新增，与原素材一一对应）：
一、结构新增——事件重设为”内部技术最后评估才发现”，并由此判定”没有任何人对’上 https 需要什么’负责“，对应第 1 节；
二、驳论新增——把”素养论”与”世界是个草台班子”合并为同一味止痛药，提出”没人有全套方案，但人人都该有个开头“与”把别人会惊讶的事，变成你已经预期的事“，对应第 2 节；
三、核心命题新增——防火的收益不是零，是负数；引入零轴，把”没记功”升级为”跨过零轴、产能被认领”；引《汉书》”曲突徙薪无恩泽，焦头烂额为上客”作古证，对应第 3 节；
四、机制新增——阻力的两柄武器 = 两个现场（第一现场用审批权拦事 / 第二现场用资源分配权拿人），并补表格对照，落点为”第二现场伪装成机会“”很多人是被喂死的，而且死的时候心怀感激“，对应第 4 节；
五、悖论新增——拆分的悖论：能快速见效的部分恰恰不能证明方向；短期见效与战略说服在结构上互斥；拿小胜利要认可等于再申请一次，对应第 5 节；
六、一致性新增——把”维护不是自驱，是自利”上调一级，得出”在一个没有长远激励的评价体系里，所有靠觉悟产生的远见，最后也都会死“；并指出”骂甲方”与”骂领导”是同一种句式，对应第 6 节；
七、代价新增——借侧的代价：能力可逆、关系不可逆；三层结构漏了”我自己“；推动者是系统里唯一不能重生成的部件，对应第 7 节；
八、行动新增——主攻先例效应的三个动作（反例台账 / 让受益者转述 / 优先后验可配对切口），落点是”你不需要他承认失效，你只需要他使用它“（使用即默许）；另附低频非索取性接触与造模具但只能给自己降本两条，对应第 8 节；
九、隐喻新增——后记庖丁解牛的反读：”他解了十九年，牛还是那头牛，也还是那么大“，对应后记；
十、视觉新增——5 张正文插图（illust-01 ~ illust-05）+ 封面 cover.png（暗调工业，层叠钢板的巨牛 + 满身细缝 + 缝中暖光 + 地上崭新未用的刀），封面解读小节为本文新增。
