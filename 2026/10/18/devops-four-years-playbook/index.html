前言

这一篇和别的不一样。它不是文章，是一份手册。

前几天我把四年的账算了一遍，写成了《顺序比努力贵：四年复盘》。那一篇是写给人看的——有前言、有收束、有情绪，读起来是顺的。

发出去之后我发现一件事：真正要用的东西，在那一篇里被稀释了。 文章需要节奏，手册需要密度，这两件事互相打架。为了让读者跟得上，我得铺台阶、给过渡、把尖锐的地方磨圆一点。而那些被磨掉的部分，恰恰是我自己下次最需要的。

所以我又写了一份。这一份不打算好看：它没有过渡句，没有修辞，全是判断、表格、清单和问句。

一句话说清它是什么：

下次我被空投到同类环境时，照着它做，不要重新想一遍。

它的读者只有一个，是我自己。发出来而不是存草稿，理由很实际：草稿会丢，而博客上的东西我还会回来翻。

正文一字未改，包括那些难听的话。

语料来源：fulizhe.github.io 全站 159 篇，重点为 2026-09-29 至 2026-10-16 的十篇，加上 2025-2026 年间「自下而上推动 DevOps」系列五篇。
写作口径：不复述文章，只做三件事——归因、提炼、排顺序。

0. 一句话结论

你不是来修一个软件的，你是来改一套成本结构的；而这四年最大的浪费不是思路错，是顺序靠试错试出来的。

剩下所有内容，都是这句话的展开。

1. 你为什么来这个部门

1.1 明面上的任务（组织说法）

「组织上把我调来这个部门时，任务说得很清楚：这个软件产品问题多，你去解决。」
——《吃苦耐劳，但你别问这苦哪来的》

这话你信了两年。它半真半假：问题确实多，但“问题多”不是病因，是症状。

1.2 真实背景（你自己记下的现场）

  • ToG 的 GIS 中小企业，约 1000 人，行业寒冬 + 政府预算收缩，公司经营困难；
  • 你本来是行业侧的人，被领导从行业部门调到平台部门「帮忙解决问题」；
  • 这个平台部门产出低，且低了很多年。

于是“为什么是我”有三个答案，逐层加深：

层次 组织给的理由 真实的理由
表层 产品问题多，需要人解决 需要一个能兜底、能扛事、保证系统不崩的技术底牌
中层 你有能力推动改进 需要一个不属于这个利益网络的人来动手，因为里面的人不会动自己
深层 —— 这台机器已经稳定运行十年，它不需要被治愈，只需要被维持；派你进去，是让你当那个维持成本

第三条最刺人，但它是对的。你后来发现“对手是稳态”，其实从你踏进门的第一天就写好了。

1.3 你的处境决定了策略

四十岁上下、跳槽成本剧增、不能一走了之——这条约束不是软弱，它是所有方法论的起点。

正因为走不了，你才没有选择“讲道理讲赢他们”这条路（那条路需要裁判），才被逼出“改价格”这条路（那条路只需要结构）。你的方法论不是想出来的，是退路被堵死之后长出来的。

这一点必须记牢：方法论的可迁移性，来自约束的同构性，不来自结论的正确性。 下次环境变了、约束变了，结论要重算，推导方式可以照搬。

2. 四年做了什么

2.1 时间线：四段，每段换一次认知

阶段 时间 你干的事 当时的认知 事后看错在哪
一、布道期 约第 1 年 讲现代软件工程常识、推 Git 分支、敏捷拆分、CI/CD 「他们不懂，我来教」 把结构问题当成认知问题；对方不是不懂，是不必懂
二、对抗期 约第 2 年 上流水线、上门禁、上测试左移，硬顶 「把门禁立起来就能逼出质量」 门禁是别人主场的规则，可以被“恶意服从”反杀
三、借眼期 第 2–3 年 禅道二次开发全套 + 与 QA 部门经理结盟，做数据闭环 「要有一个不依赖汇报的第二信息源」 方向对了，但一次塞太多，接收带宽被撑爆
四、造物期 第 3–4 年 极简可观测性、黄页、持续交付、方法论收口 「不改人，改价格」 只剩一处：顺序还是靠试错排出来的

这条曲线的价值不在“终于对了”，在于它标出了三条本来可以不用走的路——如果第一天就知道“路径里不能有‘别人会主动’”这条判据，第一、二阶段合起来那一年多，能省掉大半。

2.2 五件兵器（按可迁移性排序，不按技术含量）

# 兵器 它压的是哪种灰度 依赖 可迁移性
1 黄页（nginx + 静态页，地址与内容解耦） 归属灰度 零 ★★★★★
2 持续交付（打包频率从“一天一次都保证不了”推到“一天四次+”） 节奏灰度 零 ★★★★★
3 技术可观测性（jar 依赖式极简监控：报错 / 卡顿 / 联调） 责任灰度 零（但需要自己写） ★★★★☆
4 禅道闭环 + 钉死字段（工时、根因、流转） 口头灰度 + 时间灰度 需要一个人接住 ★★★☆☆
5 方法论本身（减摩擦工程：总律 + 五定律 + 五阶段 + 六尺子 + 九学费） 以上全部 需要一次完整实践 ★★★★★

注意第 1、2 两件排在最前面，不是偶然：它们是整套东西里唯二“完全不向任何人要东西”的，连“上层接住”都不要。你自已也说过，评价最高的成果不是最复杂的可观测性，是那个 nginx 加一个静态页。

2.3 你真正动的那一格

用一句话概括四年的全部动作：

把“验证”的价格从一小时（还常常拿不到）降到三分钟（一次点击），把“猜想”的价格从零抬到一次铁证。

这就是全部。剩下的都是这句话的施工图。

而这条动作之所以有效，是因为它同时改了两件事：

  1. 行为层面：B = MAP 里，动机接近零、触发天天有，唯一能自主拉动的只有 Ability；
  2. 结构层面：A 一高，飞轮自己转——验证容易 → 排查被执行 → 范围收敛 → 结果可见 → 别人看到好处 → 动机自己长出来。

你把第一推力全部花在了 A 上。这是四年里最正确的一个决定，而且它是唯一不需要任何人同意的决定。

3. 成果盘点

3.1 可举证的（能写进 PPT 的）

项 之前 之后
打包/发布频率 一天一次都保证不了 稳定一天四次+
故障定位 三天口水战，靠嗓门定责 五分钟以内（这是你向领导报的唯一指标）
部署包获取 拉锯式索要、私聊传文件 在线自助浏览/查找/下载（2025 年）
测试节奏 追在研发屁股后面反复重测 P1 提测次日按用例验收，一句话给过不过
责任归属 “不是我这层”可以无限循环 Java 侧从怀疑链里被摘出去，压力回流
争议成本 近百工时/几个月耗在 P1 返工（绝对成本） 争议不必发生——第一时间自证，链条当场断掉
方法论沉淀 无 一套完整体系 + CSDN 付费专栏 25 篇

3.2 不可举证的（真正的资产）

这三样上不了周报，但它们是这四年真正的产出：

  1. 一套可移植的判断力——“路径里有没有‘别人会主动’”这一条否决式判据，能在十分钟内毙掉一个看起来很漂亮的方案。
  2. 一次完整的、从零到闭环的实证——在无权力、无裁判、无资源、对手是稳态的四重约束下，把一件事做成了。这个组合条件很难复制，所以这份经验极其稀缺。
  3. 一个已经会自己转的现场——组员今年自己来用了，没人叫他们，因为账本从“你的护城河”变成了“他们的举证工具”。

3.3 必须同时承认的代价

  • 这件事永远不会“建成”。 你自己写过：打造成铁桶不是目标，是维持成本；机制一缺席，行为立刻回弹。
  • 它的价值天然不可见。 工具生效之后，争吵没有发生；没发生的事不留记录。所以“价值低”这个评价会长期跟着它。
  • 你改的是赔率，不是人品。 带马到河边，仅此而已。

4. 最贵的几笔学费（提炼成一句一条，供下次直接躲）

学费 具体形态 判据化
把“改变人”当目标 讲常识、讲道理、讲最佳实践 意愿不可外部改变；凡方案依赖“他想通了”，毙
在对方主场作战 用会议、评审、争论解决问题 对方主力技能是泥潭肉搏，你的主力是工程事实——换场地，不换姿势
漏掉节奏这一维 前四种灰度都压了，“等明天打包再看”没压 灰度空间 = 说不清 × 它持续的时间，右边那一项是乘数
一次塞太多 第一版大盘没人看 接收带宽是硬约束，一次只喂一件事
越界指认 拿证据去指“是你的问题” 无裁判时，指认必被稀释成“两家说辞”；只证伪，不指认
把预防立成 KPI 想给告警、容量治理立项 防火收益为负（零记功 + 被当空余产能征用）；只能顺手带出来
上赶着 替不在意的人配探针、垫学费 出界的那一跨需要明确对端；没对端的付出是沉没，不是投资
顺序倒置 先做最有价值的那件 第一刀挑最低阻力的；先例效应 > 入口默认性 > 内容增量
以为“建成”了 想收工 它是运行成本，不是固定资产

5. 元知识：十条可迁移的判断（不是结论，是判据）

这十条按“通用性 × 杀伤力”排序。每条都配一个当场能用的问句——元知识的价值在于能变成问句，不能变成问句的都是感想。

1. 结构 > 动机

问：他这样躲，要花多少钱？（而不是“他怎么才能变得负责”）

组织的坏不来自人坏，来自“坏的做法便宜、好的做法贵”。所以别教育、别感动、别刺激——调价格。调价格不需要任何人点头，因为价格是结构的函数，而结构在你自己的边界内就能动。

2. 一切治理 = 缩短“动作 → 结算”的时间

问：这件事从发生到被结算，隔多久？

报表、流水线、门禁、发布频率、工时统计——四件工具一个本质。“慢”之所以便宜，是因为它的账单一个月后才到，而且被稀释到看不见。

3. 无裁判时，证伪是唯一还在生效的举证

问：这件结论，需要谁点头才算成立？

需要点头的，出局。证伪只需要自己这一侧的证据，不需要对方承认、不需要第三方裁决。指认需要用可信换结论，证伪只需要用可验证换豁免。

4. 路径否决律

问：这条路径里，有没有哪个节点要求“别人会主动”？

有，立刻毙掉，不要优化它。这一条比任何方案评估都便宜：它把判断从“这个方案好不好”（要反复论证）变成“这个路径成不成立”（一眼可见）。

5. 先便宜后价值

问：这一刀，需要谁批准？

第一刀的意义不在它改了多少，在于它给后面的东西留下了落脚点。落地是往信用账户里存钱，而最值钱的花法是“先例”——“上次那个也没走审批，现在大家都在用”。

6. 放一个“物”在人和人之间

问：这件事能不能被一个“物”挡在中间？

挡不住的，多半会退化成靠嘴。入口页、钉死的字段、证据链、发布通道——间接层不减少信息，它删掉路径；而路径才是组织里最贵的东西。

7. 快只是横轴，硬度才是纵轴

问：这次反馈结算的对象，是问题，还是人？

快表态、快切割、快走流程，在速度上与证据链无法区分。只有速度没有硬度，你不是在做反馈，是在做传声筒。 反馈的效力 = 硬度 × 速度。

8. 唯一不可自控的一环是“接收者”

问：这套东西，有没有一个人在等它？

技术面可以单方面建，隔离层只要没人拦，制度面必须有人接住并往下传。如果没有，你做得再好也只是自保，永远变不成制度。诊断价值就在这里：做了很多却什么都没变，先回来查这一环。

9. 价值天然不可见，所以要提前设计“可见性”

问：它生效的时候，会留下什么痕迹？

有效 → 什么都没发生 → 没记录 → 被认为没价值 → 下一个预算周期被砍。这是一条闭环的死亡螺旋。 所以从第一天就要留一个“能换算成钱”的口径（比如：近百工时返工、三天变一分钟）。

10. 同构性：技术问题与组织问题共用一套骨架

问：这件事在技术上对应什么？

exit span 必须有 peer ↔ 越界协作必须有责任主体；连接池耗尽 ↔ 缓冲垫被撤；调用方侦探模式 ↔ 举证责任单向转移；没有监控 ↔ 没有第二条信息线。你能用技术词汇精确描述组织病理，这是你最锋利的表达方式，也是别人最难反驳的方式。

6. 快速破局 SOP：如果明天空投到同类团队

前提假设：无权力、无裁判、上层不接、对手是稳态。如果这四条里有任意一条不成立，下面的顺序要重排。

第 0 步：两周内做四张表（只读，不花一分资源）

表 问什么 用来判断
避风港清单 你们现在靠什么躲？（说不清 / 拖延 / 私藏 / 无人在场 / 等打包） 切口在哪
权力地形 谁有审批权？谁可能是接收者？谁只是传声筒？ P2 找谁
稳态判定 这个状态存在多久了？两年以上？ 该“改”还是该“共存”
怀疑清单 我最常被怀疑的是哪三件事？ 这直接就是 P1 的建设清单

四张表填完，方案就该自己浮出来了；浮不出来的，说明你还在这套结构里没看清。

第 1 步：P1 自保（零依赖，第一天开工，全程并行）

目标：任何针对我的怀疑，30 秒内可证伪。
验收标准只有一条：换个人也能复现吗？ 复现不了就是没建成。

这一步是唯一完全自主的一步，也是后面所有动作的底气来源。别跳步去做好看的东西——没有这一层，你连上桌的资格都没有。

第 2 步：P3 造物（零依赖，与 P1 并行）

放两类“物”进去，都过一次五判据（不申请任何东西 / 成本自己承担 / 不产生显性受害者 / 不动任何人的考核 / 有显性受益者）：

  • 信息层的物：固定入口页（改内容不改地址）
  • 时间层的物：把“改完 → 效果可见”的等待删掉

验收标准两条：变更时需要通知的人数 = 0；从改完到可见的延迟 ≈ 0 且稳定。

第 3 步：P2 借眼（唯一失败点）

不要试图说服任何人，给一个能被数据打动的人装上第二双眼睛。
关键动作只有一条：先给一次真实的反馈，让他看到希望。 他不是被说服的，是被“报表送到面前、他终于有了自己的眼睛”推动的。
反复失败就退回 P1+P3，不要硬撞。

第 4 步：P4 复利

拿第一次的信用记录开下一个口子。这时候你才有资格动那件“最有价值也最贵”的事。

退出判据（这条最容易被忽略，也最该写死）

如果 12 个月内 P2 始终没有接收者，且你的边界无法扩展——这个环境不值得“改造”，只值得“共存 + 提取”。

这时候正确动作不是更努力，是：

  1. 把 P1 做到极致（自保，永续）；
  2. 把精力转向可携带资产（方法、声誉、网络、作品）；
  3. 停止一切布道，只做冷酷的规则执行组件。

这不是认输，这是资产配置。 认输是“我不行”，资产配置是“这个标的的回报率不支持继续加仓”。

7. 如何进一步精进

7.1 从“改一个部门”到“可交付的方法论产品”

你现在手里是一套体系（总律 + 五定律 + 五阶段 + 六尺子 + 九学费），但它还是“你的”。

精进方向不是再加定律，是把它变成别人能直接上手的物件：

现在 应该变成
一篇长文《减摩擦工程》 一页速查卡（P0–P4 + 五判据 + 六尺子）
九笔学费（表） 一份“方案自检清单”（否决式，10 分钟过一遍）
可观测性体系 一套接入模板（换团队 = 换壳，不是从零）
禅道字段设计 一份“灰度 × 压缩工具”对照表

判据：一个新来的人，能不能只看这四样东西，在两周内把你的第一年复现出来。 能，就叫产品；不能，还只是手艺。

7.2 从“自保”到“定价权”：把资产留在可带走的寄存器里

你自己算过这笔账：组织能定价的只有工时，定不了 merit。所以你越快，活越多，价钱不动。在这个市场里加大投入不是投资，是追加保证金。

于是有三个动作：

  1. 分清抵押物和资产：绑在组织上下文里的（只有你会跑的流程、只有你懂的黑盒）是抵押物，越攒越难走；可泛化的方法、判断力、声誉、网络是资产，越攒越自由。
  2. 只投能带走的：开源项目、专栏、方法论体系、跨行业的问题解决范式。
  3. 效率剩余只换算成一样东西：反脆弱 = 冗余 = 选择权。 不是更多产出，也不是“更多产出 + 更好的证明”。

链条要重写：

快（省下时间）→ 反脆弱（冗余 / 选择权）→ 定价权（自己说了算）→ 薪水是副产品 → 自由（用减法兑现）

7.3 补三块真短板

短板 为什么重要 怎么补
向上叙事 你的价值天然不可见；不会讲，就只能吃哑巴亏 把“没发生的事”换算成钱：工时、返工、扯皮时长。不讲工具，讲账单
跨组织影响力 你的射程止于边界，而下一次的战场（Go 层）在你的边界外 从“我证伪”升级为“我定义举证标准”——把你的观测口径推成事实标准（i18n 那篇已经摸到边了）
机制设计 你现在是“经验型调价”，还没到“可计算” 读委托代理、激励相容、Goodhart 定律；目标是能预测“改这一格会引发什么反噬”

7.4 一条纪律

不要因为痛恨那个“慢”，就反过来崇拜“快”。

那个主管慢下来是套利，你慢下来是自保；动作一样，方向相反。快慢从来不是答案，效率剩余的去向才是。 这条纪律要写在自己的桌面上，因为它会在你最累的时候失效。

8. 参考理论与书单

只列真正能对上你这四年具体问题的。标了“读它解决什么”。

第一层：直接对应你已经摸到的东西（读了会确认，不会惊喜）

书/理论 对应你的哪个结论
《Principles of Product Development Flow》Reinertsen “节奏灰度”的数学版：队列、批量、延迟成本。你手推出来的“灰度空间 = 说不清 × 时间”，这本书有公式
《Accelerate》Forsgren 等 你报给领导的“故障定位五分钟”，本质是 MTTR/lead time 的 DORA 口径。读完能把你的指标换成行业通用语言
《Site Reliability Engineering》Google SLI/SLO/错误预算——“可举证”的工程化形态。错误预算这套东西，是你“让便宜动作变贵”的现成制度外壳
《Thinking in Systems》Meadows 系统杠杆点排序。你的“改价格不改人”就是杠杆点第 4 层（规则）而非第 6 层（信息流）；读完能解释你为什么总选对层级
《Tiny Habits》Fogg（B=MAP 出处） 你已经用对了一半（只拉 Ability）。这本书能补完另外两个变量的正确用法
《Nudge》Thaler & Sunstein “选择架构” = 你说的“改价格”的学术名。区别：他们改默认值，你改结算时延
《The Pragmatic Programmer》第 2 版 “select 没出问题” / “马蹄印不是斑马”。你已经引过，但值得读第 5 章“宁弯不折”——它讲的是边界

第二层：解释“为什么他们必须这样”（把道德判断换成结构判断）

书/理论 解决什么
Kerr, “On the Folly of Rewarding A While Hoping for B”（1975，论文） 一句话解释你四年的困境：系统奖励慢，却希望你快。这篇是你全部文章的学术母题
《Power》Jeffrey Pfeffer / 《Managing with Power》 无正式权力者如何获得影响力。你的“借势、借直、占位”三条，书里都有对应章节
《Men and Women of the Corporation》Kanter “权力来自获取资源与不确定性的能力”——解释为什么那个主管要垄断隐性知识
《The Evolution of Cooperation》Axelrod 你引过：赢的不是最善良的，是“善良但会还手”的。配合你的“只证伪不指认”，就是一手完整的 Tit-for-Tat
《Skin in the Game》Taleb “猜想者不担责”的本质是不对称性。这本书给了它一个名字，和一条判据：没有 skin in the game 的主张，不进入决策
《Normal Accidents》Perrow / 《The Field Guide to Understanding Human Error》Dekker 为什么“追责”必然失败、“根因”往往是幻觉。你的“证伪不指认”在这里有整本书的支撑
《Resilience Engineering》Hollnagel Safety-II：安全不是“没有事故”，是“事情在变坏时还能成功”。对应你的“底线抬高、没有终局”

第三层：元层——知识、语言与不可言说之物

书/理论 对应你的哪个发现
《Personal Knowledge》Polanyi（“我们所知多于我们能言说”） 你的“事实税”和轮扁斫轮的现代学术版。这是“隐性知识”概念的源头，比你引《庄子》更硬
《The Reflective Practitioner》Schön 专业者在行动中反思（reflection-in-action）。你四年“靠试错排顺序”这件事，本质是缺一个事后结构化的复盘协议
《The Craftsman》Sennett 匠艺与“做得好”的内在标准。给你的“二十多篇专栏”一个非功利的解释
《Antifragile》Taleb 你正在读。重点不是“反脆弱”三个字，是杠铃策略：一端极保守（P1 自保），一端极激进（P5 试验），中间全砍掉
《经济解释》/ Coase《企业的性质》 交易成本 = 你说的“路径成本”。“组织里最贵的是信息传递路径”，就是科斯定理的白话版
Goodhart‘s Law / Campbell’s Law 指标一旦成为目标就失效。你的“绝不把预防立成 KPI”是它的直接推论，但你需要知道它的全部失效模式

第四层：中文经典（你已经用得很准，可以再往下挖一层）

出处 你已经用的 还能往哪挖
《韩非子·显学》“不恃人之为吾善也，而用其不得为非也” 总纲 配合《二柄》（赏罚二柄）看：你只用了“罚”，没设计“赏”——这是你体系里唯一的空缺
《韩非子·饰邪》“龟策鬼神不足举胜” 骂请神式排查 同篇“用时日，事鬼神，信卜筮，而好祭祀者，可亡也”——组织衰败的早期信号清单
《孙子·兵势》“求之于势，不责于人” 改势不改人 配合《军形》“善战者之胜也，无智名，无勇功”——解释你为什么“有功而无名”
《荀子·劝学》“善假于物也” 间接层 配合《王制》“明分使群”——分工与边界，正是你的“射程止于边界”
《庄子·天道》轮扁“口不能言，有数存焉” 事实税 配合《人间世》散木——无用之用，你的“降频”哲学
《管子·牧民》“仓廪实而知礼节” 未用 激励前置于教化。你反对布道的理论依据

9. 最后：三条给下一次的自己

  1. 别问“怎么让他们变好”，问“这个结构在奖励什么”。 你把这句话想通用了四年，下一次应该用四天。
  2. 顺序比努力贵。 四年里最亏的不是走错路，是花一年才确认某条路根本不用走。所以第一件事永远是“排顺序”，不是“选方案”。
  3. 你能改赔率，改不了人品；能点灯，不能替人睁眼。 这条边界不是失败的证据，它是让你能干四年的原因——一旦越界，你从“点灯的人”变成“拉着人走路的人”，第二年就会耗尽。

至于那四年——它没白费。
只是如果有人早把这套东西写给你看，你不需要走其中那一年。
现在这套东西写出来了。下次，别走那一年。

后记

手册这种东西，写的时候都知道，用的时候全忘。

所以它真正的用法不是“读一遍”，是卡住的时候翻到对应那一节。想不清要不要接这件事，翻第二节；不确定这一刀该切哪，翻第六节；开始怀疑自己是不是该走了，翻第六节的退出判据。

如果你也在一套说不清的系统里，这份东西大概有七成用不上——因为它的每一条都长在我那个具体的坑里。但剩下三成是可以拿走的：判断的顺序，不是判断的结论。

封面解读

这张封面只压缩了一个判断：这是一本被翻烂的东西，不是一本被写好的东西。

那只厚到变形的活页夹 = 这份手册本身。 它鼓着，合不严，封面边缘磨出了毛边——不是精装的工具书，是天天被翻开、合上、再翻开的那一本。

书口那一排密密麻麻的索引标签 = 它的九节内容。 颜色灰扑扑的（旧琥珀、鼠尾草、浅蓝），好几枚已经被翻得歪了、卷了。这就是“手册”和“文章”的区别：文章你从头读一遍，手册你要在需要的时候一秒翻到那一页。

那条垂到桌面上的布书签 = 还没读完的那一页。 它不在书里，它掉出来了——因为这本书没有“读完”这个状态。

整幅画只有右上角一道硬光，其余全黑 = 它是给自己打的灯。 没有读者围观，没有掌声，也没有评审。这本手册的用途只有一个：在下一个黑屋子里，照见自己脚下的那一步。

一句话总结：这不是一本写给人看的书，是一本被翻烂的手册——它的价值不在写得多好，在于下次卡住时，你能一秒翻到那一页。
