减摩擦工程：如果重来一次，我按什么顺序动手

2026-10-02T09:00:00.000Z2026-10-10T14:39:31.838ZChina

前言

过去两个月我连着写了两篇。一篇把可观测性从”自保的护甲”重新定义成”善行的资格线”（见 先在岸上：可观测性不是护甲，是善行的资格线），一篇说它只能证伪、不能指认（见 从被告席上下来：可观测性只能证伪，不能指认）。

写完那天我意识到一件事：这两篇都是零件。

零件齐了，不等于你会组装。真正的问题在我心里压了四年——如果明天把我空投到一个一模一样的团队，我按什么顺序动手？

答案我很晚才拿到。这四年我干得最亏的一件事，不是思路错，是顺序靠试错试出来的。试错本身不亏，亏的是它慢：一年年过去，你才确认某条路根本不用走。

所以这篇只干一件事：把顺序一次性写死。

我给它起了个名字，叫”减摩擦工程“。理由后面会展开——组织里最贵的从来不是信息，是信息的传递路径。我这些年做的事，说穿了都是在删路径。

1. 先把牌看清楚：四条约束

讲怎么做之前，得先把”不能做什么”划掉。不划掉，后面全是空谈。

约束 含义 后果
没有权力 不能考核、不能奖惩、不能任命 任何需要”别人服从”的方案出局
没有裁判 跨团队无复盘、无根因归属裁决 任何需要”裁决”的方案出局
上层不接 不出资源，只在成果出来时收割 任何需要”资源”的方案出局
对手是稳态 这个状态存在了十年，不是暂时状态差 任何企图”改变稳态”的方案出局

四条一叠加，可行域被切得很小。我这套东西的全部内容，就是在这个小可行域里把动作排好序。

有一条推论要先立在这里，因为它是后面所有筛选标准的源头：

任何方案的路径里，只要有一个节点要求”别人会主动”，这个方案就已经死了——无论它设计得多好。

四年里我失败的那一堆，方案质量都不差。死因全部是这一条。

2. 你唯一能改的，是价格

四条约束逼出了唯一的出路：

你改不动人的意愿，也没有能力给人加装备；你唯一能改的，是各种选择的价格。

组织的坏，不来自”人坏”，来自”坏的做法便宜，好的做法贵“。

所以不要去教育人、感动人、刺激人——去调价格。

调价格不需要任何人的同意，因为价格是结构的函数，而结构可以在你自己的边界内动手。

这一条听着抽象，落地就一句话：别问”他怎么才能变得负责”，问”他这样躲，要花多少钱”。

3. 灰度定律：他们躲在哪，切口就在哪

我拿这套东西去一个陌生团队时，第一件事从来不问”你们有什么问题”——那问不出东西，得到的都是别人的说辞。

我问的是：你们现在靠什么躲？

所有的躲藏，都依赖同一件东西：说不清。汇报可以加工、时间可以拖延、信息只在私人手里、责任没有归属、连验证都要等到明天——这五种”说不清”，就是五种灰度形态。而一切治理动作的本质，都是把某处的灰度换算成可验证的事实。

灰度形态 表现 压缩工具 我的实例
口头灰度 汇报可加工，只挑对自己有利的说 报表 / 钉死的字段 禅道
时间灰度 拖延无痕，”在查了”能挂一整天 时限 / 事件时间轴 禅道的过程管理
归属灰度 信息在私人手里，”只有我知道” 入口页 / 地址与内容解耦 黄页
责任灰度 无人在场，谁都能说”不是我这层” 证据链 / Trace / 边界 技术可观测性
节奏灰度 “改完了，等明天打包再看看” 持续交付 / 发布频率 打包权的三年租约

找到灰度，就找到了切口；切口的形态，由灰度的形态决定。 这一点我在写灰度空间那篇时算过一遍（见 恐惧才是有效驱动力：用数据与根因字段，一寸寸压死灰度空间）。

但这里有个反面警告：压缩灰度 ≠ 监督人。 它的产出不是”我抓到你了”，是”解释权从一张嘴，回到事实手里”。

第五种灰度：它压的不是”说不清”，是”说清要等多久”

前四种其实是同一个维度上的事——它们都在赌”说不清”。

第五种不一样，也是我漏讲最久的一种：前四种比的是”说不清的程度”，第五种比的是”说得清的延迟”。

写成一条乘法就很清楚了：

灰度空间 = 说不清的程度 × 它持续的时间

前四种手段压的是左边那一项，把”说不清”变成”说清”。持续交付压的是右边那一项，把“说清”所需的等待删掉。

而右边那一项，是左边那一项的乘数——所以它最容易被漏掉，也最不该被漏掉。因为前面四种手段，全都自带生效延迟：

  • 你能当场证伪了——但改动要等下一个包；
  • 你能当场留痕了——但报表一天才更新一次；
  • 你能免于沟通了——但入口页里的东西还是昨天的。

只要存在一个”问题无法当场关闭”的窗口，那个窗口就是可以躲的。 而且这个窗口的形状特别适合躲：它在时间上完整、在名义上正当、在话术上无可指摘——

“我已经做完了，等明天打包了再看看。”

这句话的毒性不在于懒，而在于它是一个自我实现的预言：因为打包慢，所以不需要快；因为不需要快，所以慢是合理的。它把一个流程约束，冒充成了业务事实。（这笔账我在 打包权的三年租约：从有动机的一端，到有信息的一端 里单独算过。）

拆穿它不需要辩论——只需要让它的前提消失。 频率提上去，这句话自己就没了。

这里还有一层互补关系值得点明：

手段 它压掉的是
技术可观测性 归因的时延——当场说清”这是谁的问题”
持续交付 关闭的时延——当场把这个问题结束掉

只做前者，你只能从被告席上下来，问题还挂在那儿过夜；两个都做，”等明天打包再看看”才真正失去了立足的地方。前者让你说得清，后者让这件事过不了夜。

代价也要摊开：撤掉”等待”这个缓冲垫，对双方同时生效。 他们不能再拖到明天，你也不能——修复速度成了唯一的变量，一旦它掉下来，压力立刻回到你身上。所以这不是”变得更轻松”，是你把唯一的变量换成了自己。

而它的依赖度值得单独标一笔：它是这套东西里第二个完全零依赖的武器——第一个是黄页。改流水线不需要谁点头，装上就自动生效。这也是为什么它和隔离层同类，我把它一并归进 P3。

4. 不推动人，只让便宜动作变贵

灰度找到了，接下来是改造的手法。手法只有一条：

不要改变人的选择，只改变选项的价格。

我的三个实例，都是同一条逻辑的不同投影：

  • 怀疑原来零成本 → 让每次怀疑立刻收到一张反向传票 → 怀疑变成负收益的赔本买卖；
  • 含糊原来是默认选项 → 让含糊在报表上现形 → 含糊变贵；
  • 绕过原来无痕 → 让绕过在时间轴上留痕 → 绕过变贵。

机制是这样的：你不需要推动任何人，你只是让一个便宜动作变昂贵，行为自己就会改。

但这里有个必须钉死的区别，否则你会误读自己全部的战果：

行为改变的原因，不是”责任感上升”，而是”回避成本上升”。

这个区别决定了一件事——一旦你的机制缺席，行为会立刻回弹。 所以这类建设没有”建成了”的那一天，它的本质是运行成本，不是资产。这也是为什么我说”打造成铁桶”从来不是目标。

5. 放一个”物”在人和人之间

前面讲的是”改价格”，这一条讲”改结构”，而且它的判据最硬：

这件事能不能被一个”物”挡在人和人中间？挡不住的，多半会退化成靠嘴。

场景 没有间接层 有了间接层
给人发资料 每次变更都要通知每个人 给一个固定入口，改内容不改地址
流程落责 靠口头汇报 靠钉死的字段
排障定责 靠互相怀疑 靠证据链

我评价最高的那个成果，不是最复杂的可观测性，是黄页——一个 nginx 加一个静态页。而它值钱的地方，我过去一直说错了：不是因为它简单，是因为它是三件事里唯一不向任何人要东西的——连”上层接住”都不要。（这条的完整推演见 批准很贵，默许很便宜：一个 nginx 页面穿过组织的三年。）

它本质上是公司在内部自建了一个 DNS：大家认的是名字，改 IP 不需要通知任何人。 而更早些年我的做法是每次直接甩一个链接过去——那个”快”是假的，它只是把成本推到了下一次变更，而且随人数线性放大。

间接层不减少任何信息，它把路径删掉了。 而路径，才是组织里最贵的东西。

6. 射程止于边界，而有一环不由你控

走到这里，必须画两条界。越界即失效，这两条是我四年里最贵的学费。

第一条界：工具的射程 = 你实际能拿出证据的边界。

动作 需要的条件 在这里具备吗
证伪（”不是我”） 只有自己这一侧的证据 具备，而且完全自主
指认（”是你”） 越界的证据 + 对方的观测数据 + 一个会承认结论的裁判 第一样我有；第二样只能倒逼对方建；第三样不存在

这里我过去说错了一处，必须修：我一直把”对方的观测数据”当成一个”有或没有”的事实项。它不是——这件事在本环境里从来没有基线，对方那一侧常年也是一笔糊涂账。

真正让它们开始有数据的，是我们这一侧先立起来。当每一句”是你”都能被对面自己的数据挡回去、当”我们正常”这句话必须拿东西出来兑付的时候，它们才开始补自己的日志和埋点。

这是这套方法论里少见的正向外溢：你建自己的证据链，副产品是对面的最低观测义务被抬高了。意愿改不动，但被追问的成本改得动——这句话以前我说的是感受，现在它有了一处实证。

它的天花板也只有三个字：够用就行。够用的对象不是我，是那个具体的问题——刚好答得上，不多一格。痕迹很好认：触发式（被问到才采，我要的是常态基线，拿到的是应诉材料）、口径由它定（我拿到的是它叙事的形状，不是事件的形状）、有卸载冲动（我不催，它就降回去）。

所以这一样东西不能当主证据，只能当”对方自认”的辅助材料。拿它去打赢指认，等于把胜负押在一件我只能间接影响、对面随时能降级的东西上。

所以：在没有裁判的地方，证伪不是退而求其次，是唯一还在生效的举证方式。 射程内能拿到的，就是让怀疑变成负收益，把自己从被告席上搬下来。免责就是全部价值——而你退场之后，留在场上的人会开始互相咬，因为他们没有你的观测能力。（这套东西的另一半，见 纵火犯抱团之后：切香肠、烟囱口与产品底线的流失。）

第二条界：技术面可以单方面建；制度面必须有人接住。

面 产物 依赖 可控度
技术面 证据链（日志 / 链路 / 指标） 无 高
管理面 第二独立信息源（报表 / 字段） 必须有一个领导接住并往下传 中
隔离层 一个稳定的”物” 只需没人拦 最高

这是整套方法论里唯一不可自控的一环。 而它有操作要点，且我已经验证过一次：不要等TA觉悟，要先给TA一次真实的反馈，让TA看到希望。 TA不是被说服的，是被”报表送到面前、TA终于有了自己的眼睛”这件事推动的。

诊断价值在这里：如果你做了很多却什么都没改变，先回来检查这一环——没有接收者，你做得再好也只是自保，变不成制度。

7. 第一刀要挑最便宜的，不要挑最有价值的

最后一件事，是选第一个动作。而这里有个反直觉的结论。

落地不是终点，落地是往信用账户里存了一笔。但这笔存款有三种花法，强度差得很远：

排序 复利来源 强度
1 先例效应 最高——它证明的是”绕开审批的改造可以落地”
2 入口默认性 中——用得越广，取消它的成本越高
3 内容增量 低——依赖别人贡献

所以：第一刀要挑最低阻力的，不要挑最有价值的。 第一刀的意义不在它自己改了多少，在于它给后面的东西留下了一个落脚点。最有价值的那件，阻力最大、最需要别人点头，也通常就是让你白干一年的那件——等第一刀把路开出来再动它。

切口怎么筛，我用五条判据（前四条准入，第五条放大器）：不申请任何东西 / 成本自己承担 / 不产生显性受害者 / 不动任何人的考核 / 有显性受益者。

配一条禁令：

绝不把”预防”立成 KPI。

防火的收益是负数（零记功 + 被当空余产能征用），这一点我单独写过一篇（见 防火的收益是负数：为什么理性人不做长远优化）。所以趋势告警、容量治理这类东西，只能挂在下一次故障或下一个流程里顺手带出来，单独立项必死。

8. 上手顺序：五级台阶，五个杠杆

到这里，散件可以排成流水线了。

五个阶段（顺序不能颠倒）：

P0 勘察（只读，不花资源）——不问”哪里有问题”，问四张表：他们靠什么躲（避风港清单）｜谁有审批权、谁可能是接收者（权力地形）｜这状态存在多久（稳态判定，两年以上即按稳态处理）｜我最常被怀疑的是哪三件事（这直接就是 P1 的建设清单）。

P1 自保 · 技术面（零依赖，从第一天开工，与其余全程并行）——目标是任何怀疑 30 秒内可证伪。验收标准只有一条：换个人也能复现吗？ 复现不了就是没建成。这一步是唯一完全自主的一步，也是你后面所有动作的底气来源。

P2 借眼 · 管理面（需要有人接住一次，唯一失败点）——目标不是说服谁，是给一个能被数据打动的人装上第二独立信息源。如果反复失败，退回 P1+P3，不要硬撞。

P3 造物 · 隔离层与交付通道（不需要任何人同意）——过一次五判据，放两类”物”进去：信息层的物（入口页 / 钉死的字段 / 报表）和时间层的物（持续交付——把”改完”到”效果可见”的间隔压到零）。验收标准两条：变更发生时，需要通知的人数 = 0；从”改完”到”效果可见”的延迟，接近零且稳定。

P4 复利 · 先例变现——拿第一次的信用记录开下一个口子：”上次那个也没走审批，现在大家都在用。”

五个加速杠杆：

  1. 顺序前置。 四年的慢，很大一部分是顺序靠试错试出来的。别一上来做最有价值的那件——那是阻力最大、最需要点头、也最容易让你白干一年的一件。
  2. 路径假设检查（一条否决式判据）。 任何方案，先问”它的执行路径里，有没有哪个节点要求别人会主动”。有，立刻毙掉，不要优化它。就这一条，能砍掉四年里绝大多数弯路——因为它把判断从”这个方案好不好”（要反复论证）变成了”这个路径成不成立”（一眼可见）。
  3. 切口筛选前置。 五条判据 + 一条禁令，动手前先过一遍。
  4. 资产模板化。 可观测性的接入模板、根因字段定义、入口页骨架——换团队不是从零开始，是换壳。 这一条能把 P3 从几个月压到几天。
  5. 通道优先：先把反馈周期压短，再谈内容。 发布频率是唯一能同时拉动”动机、能力、提示”三个变量的杠杆——旧路径的摩擦随频率线性增长，新路径的成本却几乎不随频率增长，频率一到临界点，改的动力自己就冒出来，不需要说服任何人。所以”把’改完’到’可见’的等待删掉”这件事，排在所有内容建设之前。

9. 六把尺子，九笔学费

六把尺子（是自检问题，不是 KPI）：

# 问题 及格线
1 你不在，事情会不会塌？ 会塌 = 你建的是位置，不是系统
2 怀疑是否已经变成负收益？ 是 = 成本结构翻转成功
3 变更时需要通知几个人？ 0 = 隔离层建成
4 从”改完”到”效果可见”要多久？ 接近零且稳定 = 节奏灰度已封
5 灰度还剩几处、属于哪种形态？ 逐项对照第 3 节那张表
6 接收者接住了没有？ 接住过 = 制度层有入口

第 1 条是总纲，它把”我做得不错”和”我不可替代”分开——后者不是成就，是负债。

九笔学费（照着躲）：

失效模式 为什么会败
把”改变人”当目标 意愿不可外部改变，且全是在对方主场里使劲
方案路径含”上游会主动” 该节点在这个环境里从不存在
靠”有异议就会提” 公开反对很贵，所以没人反对；真武器是审批权
把预防立成 KPI 防火收益为负（零记功 + 被当空余产能）
允许”打包窗口”当挡箭牌 低频发布制造出一整夜的可乘之机；”等明天打包再看”是拿流程约束冒充业务事实
越界指认 无裁判 → 结论被”偶发””已恢复”稀释成两家说辞
寄希望于对方觉悟 稳态不会被说服
以为”把底层和问题分开”就行 上层缺的不是”好”，是”设边界并把边界变成结构”
只看技术可观测性，漏掉管理面 手里全是老板看不见的铁证

10. 整机：补漏、蓄水、上浮、注水

前面九节都是零件。如果要把它们装成一张图，是这个：

池子里的漏缝终于被补上了，现在池子开始蓄水，里面的人为了不被淹死，自然要持续上浮；接下来只需要继续注水，为了自保，他们自然就会继续往上扑腾。

拆开看，四个动作各自对上前面的零件：

池子的动作 对应 落点
补漏 把”说不清”换成可举证，糊涂账从此漏不掉 第 3 节灰度定律 ｜ 第 6 节射程
蓄水 通道优先：把”改完→可见”的等待删掉 第 3 节第五灰度 ｜ 第 8 节 P3
上浮 水位涨了，谁再糊弄谁被淹，各自就地消化 第 4 节成本翻转
注水 频率过临界点，动力自生，只需持续喂 第 8 节杠杆 5

关键在第三、四步为什么”自然”：上浮不是被谁推的，是被淹的风险逼的。 你不需要在场，也不需要派活——水在，人自己会动。

所以这套东西的落点，说到底就一句：

你改的不是人，是水位。人自己会为了不被淹死而上浮。

这也是它为什么不需要权力——推人要有手，抬水位不用。水位，是结构。

11. 回望：慢的根，不在人

回头看这四年，这个团队为什么慢，答案其实一直很具体。

  1. 不是谁懒。是说不清——一件事出了岔子，链路上每个点都能有一肚子说法，谁都像嫌疑人，又谁都不用认账。怀疑不要成本，推诿就没有代价；推诿没有代价，责任就落不了地；责任落不了地，最后就只剩一句”法不责众”——谁也别说谁。于是所有人安安全全待在原地，事情却一年一年推不动。

  2. 而现在不一样了。不是因为那批人变了，是水位变了：缝补上了，水涨起来了，含糊第一次有了代价。人还是那些人，但躲的成本，头一回高过了动的成本——于是自己就开始往前扑腾了。

至于定责之后——当事人摊手一句”问题复杂、解决不了”，那就往上顶，交到能拍板、有资源的人手里。

看起来这和过去没什么两样：问题还是没解决。但表现一样，底层已经完全不一样了:

  1. 过去卡住，是因为没人认领，是一笔谁都说不清的糊涂账；问题最终被烂在原地。
  2. 现在卡住，是因为这件事的难度，超过了当事人能调动的资源，一笔有主可循、也算得清的账。问题最终被顶了上去。

所以”进展缓慢”从来不是能力问题，是“说不清”太便宜。把它的价格调上去，进度自己会上来。

后记

写到这里，我发现这套东西其实不新鲜。古人早就说完了。

《韩非子·显学》：”夫圣人之治国，不恃人之为吾善也，而用其不得为非也。” —— 不指望人主动做好事，只让他们没法做坏事。整套东西的工程实现，就是这一句。

《孙子兵法·兵势》：”善战者，求之于势，不责于人。” —— 不苛责个人，去改势。

《荀子·劝学》：”君子生非异也，善假于物也。” —— 靠”物”把人挡在外面，不靠德性感人。

所以这篇文章要说的话，两千年前就有答案了。我用了四年才把它翻译成工程语言。

如果重来一次，我会先说这一句给自己听：

不赌人品，只封退路；不改人，只改价；能借的借一次，借不到的放一个”物”；永远待在自己的边界内。

然后照第 8 节的顺序，一步一步做下去。

至于这四年——它没白费。只是如果有人早把这套东西写给我看，我不需要走其中那一年。

封面解读

这张封面是一次结构隐喻，不是一次事件——因为整篇文章讲的不是”怎么打赢某一场”，而是”怎么在一张图上把路排好”。

深蓝黑的网格底 + 冷青的图纸线 = 结构本身。 地面上那层若有若无的网格，是全文的总前提：组织的坏不是人的坏，是结构的坏——改不动人，只能改结构。所以画面里没有一个具体的人，只有一张图。

那条唯一发光的路径，是”有节段”的。 注意它不是一个连续的光带，而是一段、一段地亮着，每段终止于一个节点——这就是顺序。全文最痛的结论是：四年不是慢在手慢，是慢在顺序靠试错试出来。这条路被画成节段，就是要说明它本来可以是被规划出来的东西。

暖橙色的光 = 你唯一能改的那样东西：价格。 底色是冷的（结构、约束、边界都是冷的），只有这条路径是暖的。冷暖的分界，就是”不可动的”与”可动的”之间的分界。

四周那十来条暗灰色的路，是一份学费清单。 它们各有各的死法：有的绕回原点、有的反复分叉又合、有的半途散掉、有的直接冲向黑色裂谷。这就是第 9 节那九笔学费的画面版——它们都不是”做得不好”，是路本身不成立。

最后，光只落在路上，不落在人身上。 全图没有一个人。这不是疏漏，是立场的声明：这套东西从头到尾，不打算指望任何人。

一句话总结：在一片只有结构、没有人的暗色蓝图上，只有一条路是亮的，而且它是被分段规划出来的——这就是”顺序先于努力”。

原始素材和基础语料（人工）

文章是写完了，回到我最开始的问题，这个过程我持续了四年多，我想要总结一套方法论和理论体系，如果下次遇到这样的团队，我应该怎么快速开展我的工作，加快改进效率。

我们的业务场景决定了没有技术问题；所谓的技能难题一百次里有 98 次是难以定位；这个定位一来是报错定位/响应不及预期，二来是请求慢甚至无响应，极少有基于长期数据进行深层挖掘的场景。这个环境长期存在一定是上层有问题，过往我居然天真想要把他们和问题分割开去。过去这几年我们试行了很多方法，不少我自己出面的是寄希望于他们的改变，事后发现都是想多了。走了不少弯路，最终发现走通的禅道流程和可观测性，没有一个和这帮人的主动性有关的——前者是领导持续的支持，当然也是我们先让TA看到希望、看到反馈；可观测性则是我基于自身的直觉，事后复盘就是越靠近用户压力越大，被迫当小工。我现在把自身打造的铁通一块，一年的持续建设把可观测性做到极致，灰度空间被压缩，现在出现问题第一时间会回溯打到底层，这使得底层被迫跟上。还有一个成功的是黄页——这个不需要审批，导致阻力无法生效，然后是有好处让它可以持续迭代，于此建立了人员沟通的缓冲带，给后续更新提供了空间。
