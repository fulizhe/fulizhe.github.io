成本的顺流：低效不会消失，它只是换个人付

2026-10-30T14:00:00.000Z2026-10-31T12:37:03.116ZChina

MindMap

flowchart LR A["成本的顺流"] --> B["传动比 1:5"] A --> C["守恒的是热"] A --> D["洞与边界"] A --> E["热被记成了功"] A --> F["举证窗口"] B --> B1["小齿轮转五圈"] B --> B2["大齿轮扛五倍扭矩"] C --> C1["能量不灭"] C --> C2["有效功蒸发"] C --> C3["热没有出账人"] D --> D1["缺陷只在洞上冒头"] D --> D2["五个人是临时判定装置"] D --> D3["划边界的人正被边界约束"] E --> E1["空转最热"] E --> E2["热是唯一能自铸的钱"] F --> F1["先到者定义事实"] F --> F2["账本用来占位"]

前言

先摆一段真实的对话。时间是中午，语气都不好。

他们研发一个人，我们测试得陪五个人。

成”陪太子读书”了。

太子也没这待遇。

BUG东边一个西边一个，跟打地鼠一样。

研发天天喊的时候，说多辛苦，又要加班。改的是个啥。

拖着大家一起加班。

然后他觉得自己辛苦，劳苦功高。

这段对话容易被读成情绪。它不是。

里面藏着四句结构判断，每一句都能拿出来验：

一、一个人动，五个人扛。这是传动比。
二、缺陷东一个西一个。这是位置。
三、拖着大家一起加班。这是外部性。
四、他觉得自己劳苦功高。这是归因。

四条连起来是一条链：成本在上游产生，在下游兑付，并且就地记在下游名下。

这篇要拆的就是这条链。拆完之后你会发现，那条链上没有坏人，只有一本记错了方向的账。

1. 传动比：小齿轮转五圈，大齿轮转一圈

齿轮组里，小齿轮带大齿轮，转速降下来，扭矩涨上去。这是减速传动——用小齿轮转五圈，换大齿轮轴上五倍的扭矩。

用大白话说：上游那一下轻飘飘的转动，落在大齿轮上，是五倍的力。

“他们研发一个人，我们测试陪五个人”——反过来读才准确：不是五个人在伺候一个人，是一个人省下的那次自检，变成了五个人轴上的扭矩。

管理者的直觉在这里通常是错的。看到五个人的团队对着一个人的产出，第一反应是”这五个人是不是冗余”。但人多不说明价值大，人多说明这一端承受载荷。

而传动比不是天生的，是被设计出来的。

上游交付一个”差不多能跑”的包，下游就要用五次验证去逼近一个本来该由上游回答的问题：它到底能不能跑。

上游的颗粒度，决定下游的载荷。 这句话是整篇的物理基础。

顺便说一句：齿轮的”大”和”小”，不看谁被灯照着，看齿数。哪颗被打光、哪颗在阴影里承重，我在另一篇里拆过（1/6的暴政：编码门槛如何扭曲了整条软件交付链路）——那里的大齿轮是视觉上的大，这里的大齿轮是力学上的大。两回事，却总被混为一谈。而账本的第一笔错账，就是从这儿开始的。

2. 守恒的是热，不是功

成本不会消失——这一条要说得准一点：守恒的是能量，不是产出。

一台没上润滑的齿轮箱，输入的功率一分不少，输出的有效功所剩无几。差额去哪了？全在齿面上磨成了热。能量一分没丢，活儿基本没干。

组织里是同一个式子。少写一行参数校验，成本不会消失，它变成了下游两个小时的问题复现。两个小时是真的，人的疲劳是真的，项目节点被推后的风险也是真的——只是这两个小时没有产出任何东西，它全部消耗在把同一个问题重新确认一遍上。

所以成本这本账，该分两栏记：一栏是功，一栏是热。进项没变，两栏的比例崩了。

而在组织账本上，这笔热没有出账人。

它不在任何人的 KPI 里，不在任何一张工时单上，不在任何一次周报的”本周风险”里。会计上这叫表外：成本真实发生了，却进不了任何一张表。表外的东西不会消失，它只在没人看的角落里累积成负债。

于是它只能被归到场上唯一在册的那个科目上：下游的加班。

无源的账，会自动记在收账的人头上。

这就是为什么下游既要付成本，又要背名字。”你们测试怎么这么多问题”、”是不是你们环境的问题”——说这些话的人未必在甩锅，他只是照着账本说话。账上没有别人。

所以上一篇写的那件事（你问效率，他答工时），现在可以接上下半句了。

那篇讲的是：他答不上效率，是因为手里没有物证，只能拿在场时间当替代性凭证。

这篇讲的是：他答不上来的那笔账，最后由谁来兑付。

两篇合起来是一句更冷的话：

举证不能的人，成本由举证能力强的人承担。

这是个很坏的均衡。因为它奖励的恰好是举证能力的反面。

3. 打地鼠：加人不平齿面

“东边一个西边一个，跟打地鼠一样。”

这句话里最值钱的不是”多”，是”东边一个西边一个”。

如果缺陷是均匀分布的，测试是可以排期的：按模块分片，按轮次收敛，工时可以估。正因为缺陷聚集在少数几个位置，测试才永远在赶场——你不知道下一只从哪个洞冒出来，只能举着锤子站在中间。

而地鼠不在随机位置冒头。它只在有洞的地方冒头。

洞是什么？是那些边界不清的地方：这个字段该谁校验，这个状态该谁置位，这个异常该谁兜，这个接口的失败语义算成功还是失败。每一处没定清楚的地方，都是一个洞。

于是测试的工时不是被数量吃掉的，是被位置吃掉的。每敲一次锤，都要重新判断一次”这次算不算问题”；而”算不算问题”本身，就是一个需要协商的问题。

《韩非子·喻老》里那段，说的是同一件事：

千丈之堤，以蝼蚁之穴溃；百尺之室，以突隙之烟焚。故曰：白圭之行堤也塞其穴，丈人之慎火也涂其隙。

注意韩非给的解法：白圭治堤，办法是塞穴，不是加巡堤的人。

堤不是被水冲垮的，是被洞漏垮的。你在堤上再加五个巡堤的人，洞还在原处——就像给齿轮箱多加五个摇手柄的人，齿面上的不平一点没变。

所以”人都测废了”不是强度问题，是收敛问题：

测试不收敛，是因为被测物没有可判定的边界。

这句话和”测试人手不够”是两个完全不同的结论，指向两笔完全不同的预算。

那这五个人到底在干什么活？先看他们被误解成了什么。

管理者听到”五个人陪一个人”，第一反应通常是：测试为什么需要五个人测一个人的东西？

这个问法问错了。正确的问法是：为什么一个人的产出，需要五个人才能判定？

五个人不是冗余。他们是一套临时判定装置——每一次交付，现场造一套标准，判完就扔，下次再造一遍。所以那五个人干的是同一件事的五遍，不是五件事。这也解释了为什么他们的工时不产出积累：临时判定是消耗品，不是资产。

用这个视角看，”再加两个人”是最贵的那个方案。它只是让临时判定更贵，还顺带确认了一件事——判定本来就是下游的活儿。

该买的是别的东西：把判定前置成可执行的规则，让”算不算问题”在提交之前就有答案（这条路我写过，见 测试左移与钢铁门禁：用流水线绞杀“隔墙抛物”的工程实战）。

这一步的收益不在测试侧，在上游。因为它把”下游陪跑”变回了”上游自证”——传动比是可以改的，前提是有人愿意去改输入端那个齿轮。

但”有人愿意”这四个字，恰恰是全部的难处。

因为改输入端那个齿轮，具体动作是把边界写清楚。而边界一写清楚，上游的解释空间就没了：再不能说”这个需求太复杂”，再不能靠”演示跑通”交差。

这事我在《1/6的暴政》里拆过（1/6的暴政：编码门槛如何扭曲了整条软件交付链路）：整条链路里，编码只占 1/6 的时间，却握着压倒性的话语权，验收标准因此从”好不好”降到”有没有”。而一头一尾之所以长期荒废，正是因为在编码主导的结构里，把一头一尾做专业，等于稀释编码环节的话语权。

所以”缺一条边界”从来不是技术问题。边界是有人有权划的；而有权划边界的人，正好是被边界约束的人。

让欠账的人去改账本——这才是真正的死结。

4. 账本把热记成了功

账改不了，退一步：先看清这本账上到底记了什么。

回到那句最刺人的话：然后他觉得自己辛苦，劳苦功高。

这不是错觉。在他的账本上，这件事客观成立。

先回到第 2 节那台没上润滑的齿轮箱：它越打滑，发热越多；有效功越少，热越显眼。如果账本只记发热量，这台机器就是全场最”高产”的。

这就是加班在这套系统里的真实身份：它是摩擦热。

上一篇我说，加班是替代性凭证。这一篇要补一句更冷的：

在这个结构里，加班不只是凭证，它是这台机器磨出来的热——而账本把它记成了功。

热有三个性质，正好对上加班：

  • 它不需要原料，也不需要设备。热是损耗的副产品，不是产出的结果。
  • 人人都能发，而且空转最热——越不干正事，发得越多。
  • 账本只给它设了科目，所以一发就被记上。

于是”越不产出别的，越有它可产”不是悖论，是热力学：产出稀缺的人，恰好是发热充裕的人。 这不是巧合，是同一件事的两面。

而热还有第二个身份：它是这家公司唯一还能自己发行的货币。铸它不需要原料，不需要设备，不需要任何人验收，人人可铸。印的人一多，”劳苦功高”这四个字就通胀；但在他那本账上，它仍然是唯一能花的钱。

热解释了它是什么，铸币权解释了它为什么能花。

所以要”给涨待遇”，在他的逻辑里是通的。你不认同，不是因为他撒谎，是因为你看的是另一本账。

这也是为什么”注意方式方法，别让领导被他们给带歪了”这句提醒是必要的：领导不是被谁带歪的，领导只是读了那本一直在记的账。场上只有一本账的时候，你不去改账本，就只能指望他改信仰。

5. 举证窗口：证据不是用来讲理的

注意收集禅道吧。到时候他们拿出来说事的时候，如果不能第一时间摆出证据，绝对他们又是胜利者。

“又是胜利者”这五个字是经验，不是悲观。

因为在事实真空里，先说话的人定义事实。这不是人品问题，是仲裁成本问题：仲裁者没有义务查证，他只能采信先到场的那份陈述。谁先到场，谁的版本就成了基线，后面所有的举证都变成了”反驳”。

而反驳的成本，永远高于陈述。

所以账本的用途不是”证明我辛苦”，是占位：在对方开始叙事之前，把事实钉在桌上。一条时间戳、一个版本号、一份请求原文，钉住一条，就少一场谈判。

这也解释了”收集禅道”和”找领导吐槽”的区别：

  • 吐槽争的是情绪的解释权，当晚有效，第二天清零。
  • 禅道争的是事实的定义权，一年后还在。

“第一时间”是这句话里最要紧的四个字。晚三天的证据不叫证据，叫辩解。

后记

那天中午我也去吐槽了。忍着不吐槽不是美德，是内伤。吐槽是有用的——它让人还能继续上班。

但它不改变归因。因为归因是账本决定的，不是情绪决定的。

所以这篇不想写成”要坚强”。结构不改，情绪没有出口。情绪不是被说服的，是被结构接住的。

写到这里我才看清，”顺流”这两个字底下有两股水，方向相反：

  • 话语权往高处流——流向门槛最高的那一环。《1/6的暴政》讲的是这一股。
  • 成本往低处流——流向议价能力最弱的那一环。这篇讲的是这一股。

两股水在同一个系统里交汇，结果必然是一句话：

说话的人不付账，付账的人不说话。

“顺流”这个词的分量也在这里：它不是传递，是倾泻。水不会往高处走，成本也不会。

这条链完整地走一遍是这样：

上游颗粒度粗 → 下游放大 → 成本无源 → 归因漂移 → 下游既付钱又背名 → 能干的人先走。

最后一步最贵。因为走的恰好是”测得动”的那批人——他们不是被工作量赶走的，是被归因赶走的。他们能忍受加班，不能忍受加班之后还叫不上名字。

而洞不会跟着人走。人走了，洞留在原地，下一批人重新开始找洞。

一个靠下游的耐心兜住的系统，就像那道堤：不是被洪水冲垮的，是被渗漏掏空的。

封面解读

这张封面是一台只有三颗齿轮的机器，而全文的论证就压在这三颗齿轮上。

自上而下、逐级变大 = 成本的顺流。 画面没有横向铺开，是竖着往下走的：小、中、大，一级压一级。这就是“顺流”的字面形状——它不是水平传递，不是接力，是从高处往低处倾泻。水不会往高处走，成本也不会。

顶部那枚冷白色的小齿轮，被一束窄光单独打着 = 上游。 它是全画最亮的地方，也是最小的地方。这一处对应第 1 节那个判断：齿轮的“大”和“小”，不看谁被灯照着，看齿数。 光打在它身上，不是因为它在承重，恰恰是因为它最轻——轻到转起来毫不费力，所以看起来最像“在动”。

底部那枚占据了半幅画面的巨大齿轮，整个浸在阴影里 = 下游。 它比顶上那颗大了五倍不止，却没有一点光落在它身上。这是全画最刺人的一处：最重的那个零件，是最暗的那一块。 它转得最慢，扛得最多，而且没人给它打光。

压在轴上的那堆黑色铁块 = 载荷。 铁块不是长在齿轮上的，是挂在它轴上的。这个细节对应第 1 节那句“一个人省下的那次自检，变成了五个人轴上的扭矩”——上游省下的东西没有消失，它被搬到下游的轴上，成了别人的负重。

底部齿轮边缘的暗红余温 = 摩擦热。 注意它不是火焰，是烧红了的金属。这就是第 2 节那个式子的视觉版：能量一分没丢，活儿基本没干，差额全在齿面上磨成了热。而热是没有出账人的——它不落在任何一颗齿轮的账上，只落在那颗被磨红的齿轮身上。

整幅画面里没有一个人 = 账本上没有别人。 这张图刻意空场。没有操作者，没有监工，没有受害者。这不是疏忽，是判断：这台机器自己就在转，不需要谁在场，也不需要谁负责。 第 2 节那句“无源的账，会自动记在收账的人头上”，在这张图里就是——机器旁边没人，账却一直在记。

那几道极细的白色箭头，只有一条路，从上往下 = 单向。 画面里找不到任何一个反向的箭头。这是最后一句判词：成本的回流，从来不在设计图上。

一句话总结：光打在最轻的那一颗，热烧在最重的那一颗，而整台机器旁边一个人也没有——这就是“成本的顺流”的全部内容。

原始素材和基础语料（人工）

缘起：一段工作群聊（已脱敏）。原始对话保留了语气，因为语气本身是证据——它说明这件事重复了多少年。

甲：你不要听他们说的”加班辛苦”，你直接说项目要的是东西。

乙：烦死了。整天测测测。人都测废了。

乙：说气死了都不为过。

乙：天天喊的时候，说多辛苦，又要加班。改的是个啥。我们天天跟在后边测，都测不过来。他们一个人，我们陪 5 个人。

甲：陪太子读书。

乙：太子也没这待遇。

甲：一群人围着转是一样的。

乙：现在主要是问题太多了。本来项目上意见就大的狠，天天出问题。东边一个西边一个，跟打地鼠一样。

甲：效率低。

乙：效率太低。拖着大家一起加班。

甲：然后他觉得自己辛苦，劳苦功高。要给涨待遇。

甲：你注意方式方法，别让领导被他们给带歪了。顺势而为。

甲：我一直说这帮人效率低，包括在行业部门的时候，还不服气。这就是我专门为此写的一篇。

乙：我中午又去找领导吐槽了。吃饭的时候。忍不了一点。

乙：因为我们是最后一环。前边任何一个环节有问题，我们的工作量就成倍增加。

甲：谁在下游谁遭殃。

甲：注意收集禅道吧。到时候他们拿出来说事的时候，如果不能第一时间摆出证据，绝对他们又是胜利者。

甲：这个过程灰色地带越多，上游部分可操作空间就越大。而人性就是天然好逸恶劳。乘数效应之下，变本加厉。

续补记录（成文过程中新增或改写的观点，供事后回溯）：

一、齿轮物理修正：初稿写“小齿轮转一圈，大齿轮转五圈”，与小带大即减速自相矛盾。改为减速增扭——小齿轮转五圈，大齿轮转一圈，但轴上扛五倍扭矩。关键判断随之更换：下游不是“转得多”，是“扛得重”。齿轮的“大”也不看谁被灯照着，看齿数（接《1/6的暴政》的封面）。

二、“守恒”改“热”：初稿同时主张“成本守恒”与“1:5 放大”，逻辑打架。改为：守恒的是能量，不是产出——输入功率一分不少，有效功所剩无几，差额全在齿面上磨成热。“单边记账”这一术语误用（复式记账本就不容单边分录），改为表外。

三、加班升级两层：先是“替代性凭证”，再是摩擦热（账本把损耗记成了功；空转最热；越不产出越有热可发），最后接铸币权（唯一能自己发行、不需任何人验收的货币）。热解释它是什么，铸币权解释它为什么能花。

四、补上“为什么上游能粗”：接入《1/6的暴政》——编码占 1/6 时间却握压倒性话语权，验收标准从“好不好”降到“有没有”；一头一尾荒废是因为专业化会稀释编码环节的话语权。由此推出：边界是有人有权划的，而有权划边界的人正被边界约束——让欠账的人去改账本，才是死结。

五、结构收缩：原六节合并为五节（原“打地鼠”与“缺的不是第六个人”本是同一条因果链的两段，中间被“加班”隔断）。合并后 §3 依次走：洞在哪 → 五个人是临时判定装置 → 加人为何最贵 → 该买规则 → 但规则要有人划 → 死结。

六、古证补全：《韩非子·喻老》补足后半句“白圭之行堤也塞其穴”——古人治堤的办法是塞穴，不是加巡堤的人。加五个巡堤的人不平齿面。

七、双流模型（后记）：话语权往高处流（流向门槛最高的环节），成本往低处流（流向议价能力最弱的环节）。两股水交汇处的判决——说话的人不付账，付账的人不说话。结尾由“烧穿/抽干”改为回归“堤”的意象：不是被洪水冲垮的，是被渗漏掏空的。

八、视觉：新增 cover.png（三级齿轮自上而下、顶部冷光小齿轮、底部阴影中烧红的大齿轮、轴上压铁块、画面无人、单向白色箭头）与 5 张正文插图（illust-01 ~ illust-05，sketch-notes 风格，图上不用任何中文字形，仅靠视觉承载）。illust-01 首版构图偏右下且大齿轮形态不清，第二版改为居中构图后重出。
