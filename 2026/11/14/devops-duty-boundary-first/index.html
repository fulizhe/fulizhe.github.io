把水澄清，把锅分开

2026-11-14T04:32:00.000Z2026-11-14T11:47:46.091ZChina

引子：一组读数

上周的统计：这个团队每个月花在 P1 级错误上，大约 50 到 100 小时。这批错误已经存在三年多。P1 修复总耗时这一列，最早是我在 恐惧才是有效驱动力：用数据与根因字段，一寸寸压死灰度空间 里加进月报的。

我没有打算让它变少。它不会变少——错误的总量是这个团队整体决定的，不在我能单方面交付的范围里（可观测性的外溢）。

能变的是另一件事：这些小时记在谁的账上。

过去它们记在一滩泥里。一个问题冒出来，领导拉一堆人一起搞，谁都在场，谁都不用认，法不责众，最后成了一笔模糊账（从被告席上下来：可观测性只能证伪，不能指认）。

我现在要做的只有一句：把水澄清，把锅分开。

一、职责区分是起点

先说清楚不做什么：不评价谁的职业道德，也不评价操守。这不是客气，是没有用。评价完，锅还在原地。

也先说清楚不跨哪一步。我想替下游把问题改掉，会被读成插手他们的事情；我不替他改，只把边界画出来，他才有地方自己动。这一步跨过去，改进还没开始就结束了。

反过来，边界不能留缝。你但凡给他一点空间，他就能把这个责任甩到你身上。不是谁存心，是成本本来就会往阻力小的那一侧流（成本的顺流：低效不会消失，它只是换个人付）。

《论语·子路》：「名不正，则言不顺；言不顺，则事不成。」这里的「名」不是称呼，是谁该干哪一段。名不定，事就没有落脚的地方。

二、三步

三步都不需要任何人批准。

  1. 第一步，先把自己绑上。 我向领导做过一个保证：问题在 5 分钟内开始解决。1）属于 Java 这一侧的，5 分钟内定位出来、开始着手解决；2）不是 Java 的问题，5 分钟内给出各方无法辩驳的证据，让下游直面他的问题，不再把各种猜想丢过来让我们调查，以缩短最终解决的总时长。

    5 分钟不是效率指标。它是先把自己这一格钉死：不管最后是谁的锅，我这一格不拖。这个数对应的是结案时间——从故障发生到能指认「就是这里」的那一段（越加人，越慢）。

  2. 第二步，把锅钉回源头。 证据的作用是让推诿接不下去。猜想一句话就能出口，验证要花一小时（吃苦耐劳，但你别问这苦哪来的），而这份成本不是随机落下的：它一直落在烟囱口那一层——最贴近出口、第一个得出来解释的那一层（这个概念出自 纵火犯抱团之后：切香肠、烟囱口与产品底线的流失）。全链路的探测由调用方一力承担，被调用方在铁证摆上桌之前只负责怀疑，我管这叫调用者侦探模式（定义见 快，只是反馈的一半）。我把这份成本先接了，换回来的是：下游没处甩。

  3. 第三步，把泥沼变成科目。 每月那 50 到 100 小时，现在是一个数。排错耗时从解释变成科目（不是第一天：把排错耗时从解释变成科目），大锅饭的前提就没了——大锅饭能维持，靠的正是分不清谁吃了多少。这一列真正的作用我也写过：不是标价，是占位，和每人每月总工时互相卡位（账本失明：为什么你越做得好，越像没干啥事）。

三、代价，和为什么走潜移默化

「各方无法辩驳」这五个字，是我给自己设的、比别人高一档的标准。别人一句推诿零成本，我要在 5 分钟内出铁证。这不是效率，是用自己这一格的产能，替整条链路补上它缺的那份验证；换回来的是让别人认账的资格。这笔钱不免费，也不会因为体系好用就变便宜。

体系好用还有个反面：好处一旦变成日常，就没人再感到它。我自己写过这个（账本失明：为什么你越做得好，越像没干啥事）——越做得好，越像没干啥事。所以我一直主动对外宣传，把 5 分钟挂在领导面前。甜头不靠组员自己记得，靠外部一直验收。

至于为什么不直接把道理讲透：制度在这个场地没有约束力。

上面定过一条裁员的规矩。有人照着办，把自己组里的人裁了。后来这个部门的名额被拖没了，制度也就没了。先照办的人付了账，规矩却没留下来。

阳奉阴违、用 200% 的力度死板执行把新政拖垮，这些机制我在旧文里写过（组织改良的深水区：破解“恶意服从”与领导者的信心重塑、ToG企业效能观察：技术壁垒的幻象与“不管理”的组织生态）。这里只补一句：自上而下的规定能被自下而上地耗掉，自上而下的道理也一样。

何况强行讲道理会被读成高高在上，一被读成那样，剩下的只有抵触。大部分人进职场是消费者心态（从消费者到投资者），熬满八小时，不为结果负责；讲「应该」走的是理智，不是本能。

  1. 对外，讲道理没有用，得让人真的感觉到威胁。我说「5 分钟内定位」，他们觉得我在吹牛，还笑；等真做到了，压力第一时间回到该在的那一格，他们才知道这是玩真的。从那以后我说的话，才有人听进去。宣布不算数，落地才算数。

  2. 对自己这一侧，是另一套：我用潜移默化，遇到问题的时候把「这样搞下去我们是吃亏的」放进去，不宣布、不立规矩。情绪是本能的通道。

四、边界

没有谁在纵容。纵容得有个主语，等于又找了个本该管却没管的人。更准的说法是：每个人都在自己所处的场景里做了最优选择，上层也是；这些选择叠在一起，就是今天这个稳态。没人有动力改它，因为改了对谁都不是当下最划算的那一步。

所以职责区分是起点，不是终点。锅钉回源头之后，压力落在了那一格，但组织还有一整套把它重新摊薄的办法：拉一堆人一起查、法不责众、拖到没人再问。压力落格，不等于压力留存。

我等的是他们出于自救，把自己那一格弄好。自救不是忽然想通了，是甩不出去了——最省事的那条路一断，人只好自己动（可观测性的外溢）。

能做的到此为止。再往前一步，就是插手。

后记

三年多，每月 50 到 100 小时。

封面解读

这张封面把全文压成一个物理场景：一只透明浅水槽，左半浑浊、右半澄清，中间只有一道竖界。 画面里没有人，也没有谁对谁错——这篇文章从头到尾不评价职业操守，只做边界。

左侧的浑水 = 过去那滩泥。 灰褐、不透明、看不见底，水面上还有打转的纹路。一个问题冒出来，领导拉一堆人一起搞，谁都在场，谁都不用认；法不责众，最后成一笔模糊账。浑水的要害不是脏，是看不穿：底下有什么、各是谁的，一概不知道。

正中那道细竖界 = 职责区分。 一道玻璃隔板，边缘有一线冷光，从上方直插到底。它不净化水，也不指认哪一侧有问题，只把两边分开。对应正文那句「我不替他改，只把边界画出来」——跨过去会被读成插手，留一点缝，责任就会顺着缝被甩回来。所以这条线必须干净，不能软。

右侧的清水 = 可观测性。 水变清之后，底下第一次看得见。每月 50 到 100 小时、5 分钟定位、各方无法辩驳的证据，都是让底可见的东西；没有它们，「谁的锅」只能靠在场的人各说各话。

底部的分格与各自的小物 = 把锅分开。 方格整整齐齐，每格里沉着一件独立的小物：立方体、圆环、短条，各守自己那一格，没有一件漂到隔壁。锅没有变少——物件一件没少，正如错误总量不会被这套动作改掉——变的是每一件终于有了格子。

从右上方落下的冷光 = 外部验收。 光不是水里自己亮起来的，是从外面打进来的。对应我向领导做出的那个 5 分钟保证：甜头不靠组员自己记得，靠有人一直在看。好处一旦变成日常照明，就没人再感到它，所以这束光必须一直在。

四周大片的深蓝灰空地 = 边界。 画面里只有这一只槽，槽外什么都没有。能做的到此为止；再往前一步，就是插手。

一句话总结：水不是被换掉的，是被分开的；锅不是消失的，是各自有了格子。

原始素材和基础语料（人工）

这个就像我之前博文里说过的，大部分人在职场就是消费者心态。
第二个就是所谓的老好人，他总觉得大家职场做戏，别把脸撕破了。对方稍微一推诿，自己就吃下了。吃来吃去，就觉得既然都这样，那就受着吧。这还是归结到前面那个消费者心态。
这样的结果是什么？就是到边缘的时候，成为模糊不清的烂账。一点问题，领导就得拉着一堆人去搞。就在法不责众之下，再加上公司的氛围，最终就是一滩稀泥。
我现在要做的就是：

  1. 用情绪激发他们天然的反抗心态，因为我要让他们意识到，这样搞下去，我们是吃亏的。
  2. 我现在制作的这一整套针对Java的可观测性体系，也已经让他们切切实实地感受到了它带来的好处。所以他们哪怕基于理性或者本能出发，也应该维护这一套，因为这会持续加强这一套，避免其他地方的锅甩到这边来。因为有句话嘛，如果我没见过光明，那我是可以忍受黑暗的。

制度问题，如果你去翻一下我过往的博文，我已经说过了，现在制度解决不了。我举个最简单的例子：自上而下的裁员制度，都被这种自下而上的拖延战术硬生生地给拖没了。你怎么弄这个制度？那个副部门经理都直接说，感觉自己被骗了。他为了遵循这个制度，把自己所管小组的人裁了，结果被部门经理用拖延战术，硬把裁员名额从这个部门拖没了。

你说的关于甜头会衰减，这一点我有心理准备，所以我一直在主动对外宣传。
比如向领导做出保证：问题会在5分钟之内开始解决，Java这边的问题5分钟之内定位出来，然后开始着手解决。如果不是Java的问题，会在5分钟之内给出各方无法辩驳的证据，让下游开始直面他的问题，别又往外甩锅，把各种猜想让Java来调查，以缩短问题的最终解决总时长，也就是所谓的效率。
我确实不会让锅变少，因为这是一个这个团队整体决定的，就像上周的统计结果表明，这个团队每周每个月花要花大概 50 到 100 个小时到 P1 级别的错误上面。这个 P1 的错误已经存在了三年多。不会变少，但是至少让产生问题根因的队伍能够直面自己发生的问题，而不是像过去一样掺着在一个泥沼里面，拉着所有人一起下泥坑里去打滚。压力才会有动力，过往这些问题很大一部分原因就是吃大锅饭，浑水摸鱼导致的，我现在就是要把这种，把这个水澄清，把这个锅分开。

职责区分才是下一步改进的起点。你要是想直接跨过这一步，他们会觉得你在插手他们的事情。你但凡给他一点空间，他就能把这个责任甩到你身上。 这就是我之前说的：我不想评价他们的职业道德和职业操守。我希望的是，他们出于自救，把自己弄好点。公正一点，这个才有希望做出改变的方式。

绝大部分普通人，你讲道理的话没用，你得真正让他感觉到威胁。
就比如我那个5分钟之内定位更新的落地。你跟他说我能做到5分钟落地，他觉得你在吹牛逼，不当回事。但是如果你真的把这个做到了，第一时间回流压力，那个时候他才知道你在玩真的。你说的话，他才真的会被听进去。
