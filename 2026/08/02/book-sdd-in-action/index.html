《SDD实战》读书感悟：从代码中心到规范中心

2026-08-02T03:00:00.000Z2026-09-05T02:48:24.791ZChina

前言

读黄佳的《SDD实战》时，我是带着急切的心情翻开的——因为书中描述的问题，恰好是我正在经历的。读完之后，有些感悟值得记下来。

1. 理论体系：行动的底气

这本书最大的价值，不在于教你怎么用某个工具，而在于提供了一套基础的理论体系和方法论。

典型如书中的 checklist——P78 的 proposal.md 辅助编写工作流，P79 的 proposal.md 完备性检查清单。这些看似简单的列表，实际作用是给你一个行动的锚点。

拥有理论指导下的行动更容易越走越顺，走的过程中也不用时刻陷入自我怀疑。

没有方法论的时候，每一步都在怀疑自己”这样做对吗”；有了 checklist，你知道该检查什么、该覆盖什么，精力就从”怀疑”转移到了”执行”。

2. 人类的位置：不完美中的生态位

第二点感悟关于人类的位置。世界上没有完美，AI 也是。

于是拥有主观能动性的人类，从中又找到了自己的生态位。AI 不完美，意味着它需要被引导、被纠正、被补充——而这些恰恰是人类擅长的。

生命会自己找到出路。

这句话我一直记得。作为一个一直期待 AGI 到来的人，读完这本书后我再次确信：人类不会很快从这场游戏中出局。 AI 的不完美，恰恰是人类价值的证明。

3. 声明式的未来：又一次佐证

编程语言领域一直有命令式和声明式的区别。SQL、LINQ 属于后者——你描述”要什么”，而不是”怎么做”。

在我早期看过的经典书籍里，作者非常笃定地预言：未来是声明式的未来。而 AI 辅助下的 SDD 流程，算是又一次佐证了这个判断。

SDD 的本质就是：你写规范（声明），AI 去实现（执行）。你定义”要什么”，AI 负责”怎么做”。这不就是声明式范式在更高层次上的回归吗？

4. Vibe Coding 与 SDD：探索与建设

书中对 vibe coding 和 SDD 的区分，总结得很精辟：

Vibe coding 负责探索，SDD 负责建设。

具体来说，可以用两天时间进行 vibe coding，快速构建一个原型给用户试用，验证方向。但一旦方向确定，准备正式构建系统时，就必须切换到 SDD。

Vibe coding 的诱惑在于现在就能看到结果；SDD 的优势在于以后不用重来。

前者满足即时反馈的欲望，后者保障长期的可维护性。探索阶段用前者，建设阶段用后者——不是非此即彼，而是阶段性的工具选择。

5. AI 的定位：放大器而非替代者

作者最后的寄语，我认为是全书的点睛之笔：

不要将 AI 当做替你思考的人，而要将它当成放大你思考价值的工程系统。

AI 时代，软件研发从”以代码为中心“转换到”以规范为中心“。在这样的转变下，清晰的表达能力比编程能力更具价值。你能把问题定义得多清楚，决定了 AI 能帮你做到什么程度。清晰定义问题的能力，弥足珍贵。

6. “苦劳”的终结

最后一点，关于行业陋习。

过往有句话叫”没有功劳，也有苦劳”。以往编码的工作量是迈不过去的坎——代码量本身就成了某种”苦劳”的证明。这导致不少不思进取的研发人员卡着生态位，进度缓慢，拿着苦劳邀功。

AI 时代，这一点陋习终于可以被有效遏制了。 当编码不再是瓶颈，”苦劳”的护城河就消失了。能留下来的，是真正能定义问题、设计方案、驱动结果的人。这是好事。

后记

接下来，我要主动实践书中的内容，结合自身经历和感悟，总结出适合自己的工作流程。理论只有落地为实践，才真正属于自己。

封面解读

这张封面是一幅关于”转化”的视觉隐喻，压缩了全文的核心命题。

左侧的碎片化网格 = 命令式代码时代的混沌。 那些扭曲、缠绕的 wireframe 代表过去以代码为中心的开发方式：每一步都要亲手操作，细节纠缠，难以维护。这是 vibe coding 如果 unchecked 会走向的终点，也是传统软件工程中常见的债务累积。

中央的蓝图卷轴 = 规范与声明式的核心。 发光的 cyan 网格线、测量标记和几何注释，代表 SDD 的核心——清晰的规范先于实现。卷轴不是终点，而是转化的媒介。它承接左侧的混沌，将其纳入结构。

右侧的结晶化建筑 = 规范驱动的可靠系统。 从蓝图表面升起的 beams、arches 和 structural frameworks，代表当规范足够清晰时，实现会自然”结晶”出来。这不是 AI 替人思考的结果，而是人的思考被规范化之后，AI 将其放大的产物。

从深蓝到青色的色彩渐变 = 从怀疑到确定的认知转变。 背景的 deep navy blue 象征不确定和混沌，而蓝图和建筑发出的 cyan 光芒象征清晰和方向感。整幅画面的光影逻辑，与文章从”自我怀疑”到”行动底气”的叙事完全同构。

一句话总结：蓝图卷轴连接了混乱与秩序，正如规范连接了人的思考与 AI 的实现——这才是 SDD 的真正图景。
